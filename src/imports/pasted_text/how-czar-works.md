Financial activity

# ANIMATION

Introduce subtle motion to communicate that CZAR is actively processing financial information.

Use:

- small financial event signals moving through the connection
- subtle opacity/scale transitions
- gentle node activation when a signal reaches a stage
- cards/elements appearing with a small translateY + opacity animation when entering viewport
- very subtle looping movement

Animation must be:

- slow
- elegant
- restrained
- purposeful

The animation should communicate SYSTEM ACTIVITY.

Do NOT use:

- bouncing elements
- excessive parallax
- flashy particle effects
- aggressive scaling
- distracting infinite animations

Respect prefers-reduced-motion.
